How it works

From Markdown to published post in four steps

Run the converter online via GitHub Pages or save app.html to your computer to run it directly in your browser.

1

Open the converter

Click Launch Converter on this site or double-click your downloaded app.html file.

2

Paste Markdown or WordPress HTML

Paste your raw Markdown guide—or paste messy HTML copied out of an existing WordPress post—into the input box.

3

Convert & review Checks

Click Convert, inspect the live preview, and review the Checks panel for any free-plan warnings.

4

Paste into WordPress.com

Click Copy HTML, add a Custom HTML block in your WordPress editor, and paste your code.

WordPress.com Free Plan Rules

Platform rules that shape how this converter works:

NO JSNo JavaScript in posts: WordPress strips <script> tags, so the tool runs here or on your PC.
NO CSSNo custom stylesheets: Styling must be added inline on each element.
NO IFRAMESNo embedded apps: Tools cannot be embedded inside a post via iframe.
ALLOWEDCustom HTML blocks: Accepts clean inline-styled HTML tags.
ALLOWEDExternal links & uploads: Link to GitHub Pages or host the single HTML file.
Usage guide

Three ways to run the converter

Because WordPress.com free plans do not execute embedded JavaScript inside posts, run the tool using whichever option fits your workflow best.

1. Online via GitHub Pages

Open aatayyab.github.io/MarkDownToHTML/app.html in any browser with zero setup or installation.

2. Locally on your computer

Download app.html to your local drive and double-click it to open in Chrome, Edge, Firefox, or Safari.

3. Self-hosted on your own site

Upload app.html to any basic web host or rename it to index.html inside any folder on your domain.
