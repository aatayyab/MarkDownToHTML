# MarkDownToHTML — Markdown to WordPress.com HTML Converter

- **Website:** [https://aatayyab.github.io/MarkDownToHTML](https://aatayyab.github.io/MarkDownToHTML)
- **Live Converter App:** [https://aatayyab.github.io/MarkDownToHTML/app.html](https://aatayyab.github.io/MarkDownToHTML/app.html)

A free, private, single-file browser tool that turns Markdown into clean, inline-styled HTML ready for a **WordPress.com Custom HTML** block—and cleans up messy HTML copied back out of WordPress.com.

## Files Included
- `index.html` — Product overview website
- `app.html` — Standalone single-file converter application (runs online or offline)
- `assets/icon.svg` — App icon and favicon
